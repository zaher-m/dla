Disagreement, directly

How many of each region did each model find?

One row per model, one column per canonical class, for the page selected above. The consensus row is the median count across models — not ground truth, but the field's collective answer. Cells are shaded by distance from it, so a model that sees three tables where everyone else sees one is immediately visible.

Counts are after the class filter and confidence floor set in the viewer, so they match exactly what is drawn above.

Measured, not judged

Geometry against the PDF's own content stream

These are not accuracy scores against human labels — there are none for this document. They are geometric agreements with what the PDF itself declares: where its glyphs are, where its images and vector art are, where its ruling lines are. A born-digital PDF answers those questions exactly. For a scanned document there is no text layer to compare against and these columns will be empty; the visual comparison above still works.

Safe to write, or not

What each system's pages were decided to be

Every page is checked against the structure the PDF itself declares and then decided: accepted and written downstream, escalated to a reviewer with the reason in words, or deferred because this pipeline handles born-digital pages and that page is not one. A page escalates when a blocking check fires or when a blocking check could not run — an unavailable check is never read as a pass.
